# mag_nav — симулятор навигации по вращающемуся магнитному маяку

Порт MATLAB-проекта на Python. Определяет **позицию** приёмника по a/b-параметрам
первой гармоники сигнала вращающегося магнитного диполя. Ориентация в текущей
версии **не определяется** (рамки приёмника и маяка считаются совпадающими).
Рабочая область — **1-й квадрант** (`x, y, z ≥ 0`).
