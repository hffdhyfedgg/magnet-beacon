# Матлаб код по магнитному маяку

Это не структурированная старая версия кода реализующего оценку погрешностей и навигацию по магнитному маяку. Здесь будут приведены комментарии по файлам в проекте.

Код основан на статье: https://www.researchgate.net/profile/Shuang-Song-28/publication/258793107_An_Electromagnetic_Localization_and_Orientation_Method_Based_on_Rotating_Magnetic_Dipole/links/5834f49108aef19cb81f9218/An-Electromagnetic-Localization-and-Orientation-Method-Based-on-Rotating-Magnetic-Dipole.pdf

Код в проекте может содержать ошибки или устаревшие/не работающие реализации, но основные проекты работают без проблем.

Вместо `.mlx` и `.mlapp` файлов есть директории с окончанием `_mlx` или `_mlapp` -- это распакованные архивы матлаб-архивов `.mlx` и `.mlapp`.

## Состав

Вывод формул осуществляется во многих местах. Иногда дублируется.
В `navigation.mlx` можно найти вывод основных формул. На основе него были созданы примитивы: `CalcR.m`,`CalcX.m`,`CalcY.m`,`CalcZ.m`,`CalcB.m`,`CalcRotMatrix.m`,`CalcRotMatrix_matr.m`,`All_fnB_fnro.mat`,`bx_long.mat` и так далее. Это основа для навигации.

Версии функций с примитивами могут отличаться. Нужно внимательно проверять, какая реализация соответствует математической модели статьи и коду в `navigation.mlx`. На пример в `Последняя версия расчётных функций Анализ погрешностей определения углов/` формулы могут отличаться.

В `SolenoidABFormuls.mlx` есть вывод формул для описания поля маяка на базе соленоидов. Соленоид задаётся как тонкий отрезок, с равномерной по длине и меняющейся по гармоническому закону во времени удельным магнитным моментом (теслы на метр в квадрате на метр; Тл^2/(м^3)).
На базе этого файла сделан класс `CreateABParameterGenerator.m`, создающий генератор поля соленоида. Это рабочая модель реального маяка, использованная для оценки ближней ограничивающей навигацию зоны.

Файлы `NoizeSimulationAnglesAngles.m`, `NoizeSimulationAnglesCord.m`, `NoizeSimulationCordCord.m`, `NoizeSimulationWithMNK.m` -- симуляции навигации в шумах, при изменении разных степеней свободы положения объекта.

В `Исследование рассхождения моделей вблизи соленоида/` хранится первая модель рассмотрения как ведёт себя алгоритм оценки положения и углов, если поле маяка создают протяжённые соленоиды. После были построены ограничивающие поверхности в `Поверхности привышения расхождения по координатам/`.
